# P1 — Universal Learning Root

This workset establishes one common contract for learning across languages, mathematics, science, engineering, technology, arts, design, business, economics, law, humanities, social science, education, life/work, and research.

## Mathematical root

The existing V3 assurance algebra remains the mathematical root:

S = product of declared dimension domains

and the logical coverage target may be expressed as:

|S| <= 10^1000

The target is never materialized. Actual learning and assurance operate on finite deterministic projections of the declared space.

## Knowledge model

The root distinguishes:

- FACT
- OBSERVATION
- MEASUREMENT
- MODEL
- HYPOTHESIS
- THEORY
- INTERPRETATION
- OPINION
- IDEA
- FICTION
- SIMULATION
- UNKNOWN

UNKNOWN is a first-class state. Missing information is not silently promoted to knowledge.

## Universal domains

The contract provides domain anchors for:

- Language
- Mathematics
- Science
- Engineering
- Technology
- Arts
- Design
- Business
- Economics
- Law
- Humanities
- Social Science
- Education
- Life and Work
- Research

These are extensible anchors, not a finite encyclopedia. New subjects may be learned under the same contract.

## Understanding

Knowing a record is not the same as understanding it. Understanding above UNKNOWN requires evidence. Understanding records retain evidence identities and limitations.

## Self-model

The learning root records:

- known identities;
- unknown identities;
- conflicted identities;
- active goal;
- current state;
- next step;
- authority scope.

This is continuity state, not a claim of consciousness.

## Questions, assumptions, and decisions

Open questions remain trackable. Assumptions are explicit. Decisions retain rationale. Supersession must preserve history.

## Universal learning lifecycle

UNKNOWN
-> discover prerequisites
-> learn
-> practice
-> test
-> evidence
-> confidence
-> apply
-> feedback
-> correction
-> learn again

Knowledge, understanding, and capability remain distinct states.

## Relationship to Workset 5

The pipeline remains:

Observation -> Pattern -> Candidate -> Sandbox -> Test -> Evidence -> Confidence -> Promotion Gate

The Universal Learning Root supplies shared semantics. Confidence remains a separate bounded projection and is not promotion authority.

## Authority and resource boundary

The root is data-only. It does not:

- execute candidate procedures;
- create workers or queues;
- schedule work;
- grant permissions;
- promote skills;
- modify Core Skills;
- modify branch protection;
- merge pull requests;
- rewrite history.

Learning can expand knowledge without expanding authority.

## Extension rule

Future disciplines, languages, techniques, and domains do not require a new root. They must remain scoped, provenance-bearing, evidence-bound, contradiction-aware, and authority-safe.
