# V3.5 Hardening & Stabilization Plan

Status: working design / evidence plan
Baseline: `main` at merge commit `ddee313` (PR #117)

## Objective

Close V3.5 without introducing V3.6/V3.7 feature work. The window between the V3.5 Worker Pool work (PR #95) and the merged 30-unit Assistant Mesh (PR #117) is treated as a hardening, integration, regression, and evidence phase.

## Gates

### 1. Worker Pool (#95)
- Sync `agent/v3.5-worker-pool-hardening` with current `main`.
- Resolve only real merge conflicts; do not redesign unrelated code.
- Verify bounded execution, queue/backpressure behavior, retry/failure handling, completion accounting, and DLQ/replay integration.
- Re-run Actions and retain run/evidence references.

### 2. 30-unit Assistant Mesh (#117)
- Treat merged state as the integration baseline.
- Verify 10 Enterprise + 20 Flutter units.
- Verify registry, orchestrator, and contract consistency.
- Do not rewrite the merged contract merely to accommodate #95.

### 3. Regression
- V3.4 DLQ/Replay preservation.
- Unified Master integrity.
- Existing V1 preservation requirements.
- Clean-install / install-gate evidence where applicable.
- Endpoint and workflow regression evidence.

### 4. Actions / Evidence
- Inventory relevant workflows and required gates.
- Prefer deterministic, reusable validation over duplicated ad-hoc checks.
- Record commit SHA, workflow run, job, and artifact references for each gate.

### 5. Contract Freeze Candidate

Freeze is allowed only when all of these are green:

- API contracts
- DLQ/Replay
- Worker Pool
- 30-unit Assistant Mesh
- Flutter contract
- Orchestrator
- Unified Master
- Preservation/regression
- Actions
- Evidence completeness

## Exit criteria

`V3.5 Stable` may be declared only after #95 is merged and the post-merge `main` regression gate passes against the combined state of #95 + #117.

Until then:

- V3.6: not created
- V3.7: not created
- No unrelated architecture rewrite
- No speculative feature expansion

## Working sequence

```text
#95 sync
  -> conflict check
  -> Worker Pool validation
  -> Actions/evidence
  -> #95 merge
  -> post-merge main regression
  -> contract freeze
  -> V3.5 Stable
  -> only then design V3.6
```
