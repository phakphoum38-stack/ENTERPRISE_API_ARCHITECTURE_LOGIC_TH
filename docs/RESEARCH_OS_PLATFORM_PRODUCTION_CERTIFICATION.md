# Research OS Platform Production Certification

This is the final qualification layer over the canonical Platform. It does not create a new runtime or authority.

## Qualification boundary
- canonical Platform spine and registry
- Laravel runtime composition
- bounded Recon/Repair
- failure/recovery semantics
- observability and lineage
- AI Code Writer boundary
- Workflow → Event/Queue → Stateless Worker invariant
- Windows/Web/iOS product surfaces
- Unified Final Gate

Certification is evidence-driven. Unknown, unresolved deferred work, failed checks, provenance mismatch, or SHA mismatch cannot be treated as PASS.

Unified Final Gate remains the only release authority.
