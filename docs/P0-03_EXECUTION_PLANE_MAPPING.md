# P0-3 Execution Plane Mapping\n\nP0-3 maps existing AEOS, API, V3, and Friend execution objects onto the canonical identity federation. It does not create a new task model, queue, scheduler, or state machine.\n\nAPI may create a new native task_id on retry; V3 may retain the same native queue task_id while incrementing its retry counter. Both map to the same canonical task/run lineage with a unique canonical attempt_id.\n\nNative identities remain authoritative inside each plane. The binding is an immutable correlation record, and lineage mismatches fail closed.\n
