Agent prompt examples for `Enterprise API Architect`.

Usage:
- Copy a template and fill the placeholders before sending to the agent.
- Keep prompts focused: state the file(s), desired outcome, and any constraints.

Included templates:
- `api-contract-update.md` — draft an API contract change as PR-ready.
- `review-api-contract.md` — review an existing contract and suggest minimal edits.
- `release-gate-checklist.md` — produce a release gating checklist for API changes.
