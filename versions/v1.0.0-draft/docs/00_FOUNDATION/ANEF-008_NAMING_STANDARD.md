# ANEF-008 — Naming Standard

Status: Draft

## Purpose
Define mandatory naming conventions for documents, repositories, modules, packages, APIs, events, branches and versions.

## Core Rules
- Use consistent, descriptive names.
- Use PascalCase for types.
- Use camelCase for variables.
- Use kebab-case for repository and branch names unless documented otherwise.
- Prefix ANEF documents as `ANEF-###`.
