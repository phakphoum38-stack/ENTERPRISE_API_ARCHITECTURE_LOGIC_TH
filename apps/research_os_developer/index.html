โดยไม่แตะไฟล์จริง

Trial Mode ใช้เฉพาะ workspace และไฟล์ตัวอย่างที่สร้างขึ้นสำหรับการทดลอง ไม่มีการสร้างบัญชี ไม่มีสิทธิ์ถาวร และไม่มีการเข้าถึงไฟล์ส่วนตัวของเจ้าของไฟล์

Developer แบบเต็มต้องลงชื่อเข้าใช้

ทดลองได้

  • ดูไฟล์ตัวอย่าง
  • ค้นหา demo workspace
  • ดูตัวอย่าง Code / API
  • จำลองสิทธิ์ Read-only

จำกัดใน Trial

  • แก้ไขหรือลบไฟล์
  • Commit / Push
  • เปิดไฟล์จริงหรือ private workspace
  • อนุมัติหรือจัดการ Grant
